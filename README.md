# 信用金庫向け「用品管理システム」 (Shinkin Supplies Management System)

信用金庫の営業店（フロント）と本部（バックオフィス）間における、一般消耗品および厳格管理品（通帳・証書・手形など）の発注・承認・在庫管理・シリアル番号受払管理を行う業務システムです。

Pythonの **Streamlit** で即座に単体実行できる完全なスクリプト（`app.py`）および、Webブラウザ上で動作するReactプレビュー画面の両方を備えています。

---

## 🌟 主な機能

### ① ダッシュボード（権限別最適化）
- **営業店ユーザー**:
  - 今月の店舗消耗品予算および消化額・消化率プログレスバー
  - 自店舗の発注申請ステータス一覧（承認待ち・承認済・却下）
- **本部管理者ユーザー**:
  - 全営業店の月間予算消化状況テーブル＆比較チャート
  - 未処理の「承認待ち」申請件数アラート
  - 安全在庫割れアラート（要仕入補充品目の即時通知）

### ② 用品発注申請（営業店向け）
- 「一般消耗品」と「厳格管理品（通帳・手形用紙等）」のタブ分割カタログ
- 品名、単価、本部在庫状況、数量スピンボックスによるリアルタイム金額試算
- 発注申請時に自店舗の月間予算消化枠へ自動反映

### ③ 承認・出荷手配管理（本部向け）
- 全営業店から届いた申請の個別審査（承認／差戻し・却下）
- **厳格管理品（通帳・手形）のシリアルナンバー帯割当機能**:
  - 承認時に払出現物のシリアル番号帯（例: `TK-2026-0301 〜 TK-2026-0500`）を入力・確定
  - 用品マスタの在庫減算および「厳格管理台帳」への自動台帳登録
  - 却下時の営業店予算自動返還処理

### ④ 在庫マスタ ＆ 厳格管理台帳（本部向け）
- **本部センター在庫管理**: 全用品の在庫数、安全在庫数、評価額一覧、仕入入庫登録機能
- **厳格管理品 払出台帳**: 金融庁検査・内部監査対応のシリアル番号帯、払出先店舗、払出年月日、承認役席の追跡記録
- **CSVエクスポート**: 監査証跡用のCSVダウンロード対応

## 🚀 ローカル環境での起動方法 (Streamlit)

Python 3.9以上がインストールされた環境で以下を実行してください。

```bash
# 1. 依存ライブラリのインストール
pip install streamlit pandas

# 2. アプリケーションの起動
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開き、全機能を検証できます。
